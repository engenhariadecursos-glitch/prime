# Frontend Design Principles

> Guia de design para orientar todo o frontend dos projetos.
> Salvo em 2026-06-14.

## 1. User-Centered Design
- Design for your users' needs, not assumptions
- Conduct user research and testing
- Create personas to guide decisions
- Test with real users throughout the process

## 2. Clarity & Simplicity
- Remove unnecessary elements (less is more)
- Clear visual hierarchy guides attention
- Use whitespace effectively
- Keep interfaces intuitive and self-explanatory

## 3. Consistency
- Use a unified design system across all pages
- Consistent typography, colors, spacing, and components
- Predictable patterns reduce cognitive load
- Maintain brand identity throughout

## 4. Accessibility
- Ensure keyboard navigation works
- Provide sufficient color contrast (WCAG compliance)
- Use semantic HTML
- Include alt text for images
- Support screen readers

## 5. Responsive Design
- Mobile-first approach
- Flexible layouts (flexbox, CSS grid)
- Readable text at all screen sizes
- Touch-friendly interaction targets (48px minimum)

## 6. Performance
- Fast load times improve user experience
- Optimize images and assets
- Minimize CSS/JavaScript
- Lazy load content below the fold
- Prioritize Core Web Vitals

## 7. Visual Hierarchy
- Size, color, and contrast direct attention
- Most important elements are prominent
- Logical flow guides users through content
- Use typography scale consistently

## 8. Feedback & Affordance
- Users know what's interactive (buttons look clickable)
- Provide immediate feedback (hover states, loading indicators)
- Error messages are clear and helpful
- Success states confirm user actions

## 9. Navigation
- Clear, intuitive structure
- Users always know where they are
- Consistent navigation placement
- Breadcrumbs for complex hierarchies

## 10. Emotional Design
- Create positive emotional connections
- Thoughtful micro-interactions
- Personality that matches your brand
- Delight in small details
